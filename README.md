## 🚀 Publishing

このサイトは GitHub Pages を利用して公開しています。

1. リポジトリにHTML、CSS、JavaScript、画像などのファイルを追加・更新します。
2. 変更をGitHubに push します。
3. GitHub Pagesの設定に従ってサイトへ反映されます。

各作品はフォルダごとに管理し、フォルダ内に `index.html` を配置することでページを公開できます。
